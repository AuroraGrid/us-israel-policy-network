# The U.S.–Israel Policy Network

A public, source-audited research website built with AURORA GRID and RECORD LOCK methods.

## Live site

https://youname-it.vercel.app/

## Purpose

This project examines the institutional mechanisms shaping U.S.–Israel policy, including campaign finance, lobbying, security assistance, diplomacy, intelligence controversies, surveillance policy, and historical friction.

The project separates:

- verified facts;
- supported reporting;
- analytical inference;
- unresolved claims;
- claims not established by the available record.

It does not assign collective responsibility to any religion, ethnicity, nationality, or diaspora community. Claims are evaluated at the level of the named institution, organization, official, donor network, government, or documented mechanism.

## Core sections

- scope, terminology, and evidentiary rules;
- campaign finance, lobbying, and aid;
- security architecture and regional diplomacy;
- intelligence and surveillance controversies;
- interactive claim ledger;
- source register and revision standard.

## Analytical design

Every consequential claim is intended to be traceable to:

1. a dated source;
2. an evidence classification;
3. a counterargument;
4. a binding constraint;
5. a condition that would change the assessment.
