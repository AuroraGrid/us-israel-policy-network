# The U.S.-Israel Policy Network

A public, source-audited research website built with AURORA GRID / RECORD LOCK methods.

## Purpose

This project separates verified record, supported reporting, inference, unresolved claims, and claims not established by the available record.

## Deployment

This repository is a static site. Deploy the repository root to Vercel with no build command and `index.html` as the entry file.

## Method

- Fact is separated from inference.
- Claims are evaluated actor by actor.
- Contested claims include constraints and uncertainty labels.
- The project does not assign collective responsibility to any religion, ethnicity, or nationality.
